# Sales-Revenue-Dashboard
Sales & Revenue Analysis Dashboard

Overview

This project is an interactive Sales & Revenue Dashboard developed in Microsoft Excel to analyze sales performance and generate business insights.

Dataset

The dashboard was built using a Chocolate Sales Dataset containing 1,094 records.

Dataset Fields

-Sales Person
-Country 
-Product
-Date
-Amount(Revenue)
-Boxes Shipped

The dataset was analyzed to identify revenue trends,top-performing products,country-wise sales performance and overall business insights.

Dataset Source : Kaggle

Features

- Total Revenue KPI
- Total Sales Records KPI
- Total Boxes Shipped KPI
- Top Product Analysis
- Revenue Trend by Month
- Revenue by Country
- Interactive Slicers for filtering
- Business Insights Summary

Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

Key Insights

- Total Revenue Generated: $6.18M
- Top Product: Smooth Silky Salty
- Highest Revenue Month: January
- Top Revenue Country: Australia
